# Sebastian's JSC Assets

This repository contains a number of [Jamf Setup Checklist](https://github.com/Jamf-Concepts/setup-checklist) related resources that I have created or modified to facilitate the onboarding of my endusers, that may be useful to others looking to have a similar onboarding procedure. 

Any and all suggestions and changes are welcome! If you find any places things could be improved, or would like to add a new step that others could use, you're more than welcome to!

This repo is divided into three sections that work in tandem with each other:

* **HelperConfigProfiles** contains configuration profiles that help in either configuring permissions for JSC, or applications that may be set up using JSC.

* **HelperScripts** are shell scripts that are intended to be invoked by JSC, either to provide extra functionality or to improve the user experience.

* **ScriptSteps** are configurations that can be directy added into the JSC configuration profile in order to add a step to the user experience.

More information on each asset can be found in their respective folders.
